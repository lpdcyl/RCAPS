# RCAPS 第三个工作点：仿真证据闭环（2026-10-24）

## 核心研究问题

异构流水线放置导出的合法 DAG 往往有远多于副本链的路径。完整路径空间可能
绕开慢链路，也可能打散持续生成的 Decode 会话，增加每个输出 token 的 GPU
执行工作。**给定放置，应向在线路由器开放哪些边，才能用较少 GPU 工作
维持吞吐与延迟？**

## 三个工作点如何相接

1. **异构放置与合法执行图（M1/M2）**：确定每张 GPU 的层段与副本结构，
   导出可达的层兼容 DAG。M1 是合法性表示，不单独主张收益。
2. **在线请求选路（M3）**：在给定边集上根据实时 GPU、链路和活跃会话
   状态为 Prompt 选完整路径，并将该路径绑定给后续 Decode。
3. **拓扑约束路径准入（本次工作）**：在两者之间，始终保留规范副本边；
   只增补能绕过慢规范边的高速跨副本边。这样 C1 单集群、C2、C3
   都收窄为规范图；C1 三集群仍保留 4 条高速绕行边。

完整接口：**放置 → 合法 DAG → 准入 DAG → 实时路由 → 执行数据反证/验证准入规则**。

## 主结果

以下均为 Helix 离散事件仿真，固定放置、同到达轨迹、1800 秒窗口、
三种子 0/1/2。GPU 秒/输出 token 是各 GPU 窗口忙碌比例之和除以输出 token/s，
包含 Prompt 与 Decode 工作。

| 资源池 | 准入边 / 完整边 | GPU 秒/token 相对 V3 | P95 TPOT 相对 V3 | 吞吐相对 V3 | 判定依据 |
| --- | ---: | ---: | ---: | ---: | --- |
| C1 单集群 | 36 / 62 | −45.87% | −9.46% | +0.67% | 原正式协议改善，独立复验逐格一致 |
| C1 三集群 | 30 / 58 | −29.73% | +1.81% | −0.03% | 原正式协议 +2%/−0.5% 非劣效，通过；不是优于 V3 |
| C2 | 26 / 46 | −73.15% | −0.41% | +0.34% | 新注册的资源效率联合门槛，通过 |
| C3 | 12 / 14 | −32.74% | +0.33% | +0.01% | 新注册的资源效率联合门槛，通过 |

C1 的 GPU 工作指标是在原有正式数据上的补充分析。C2/C3 的资源效率主指标
来自先看到 C1 与 C2/C3 短窗口趋势，再**单独注册**长窗口协议；正式种子上
此前没有运行过该门控候选。C2/C3 的历史 V3 对照有旧执行源码哈希，
已在当前运行时重跑六格；轨迹、路由、GPU 忙碌、请求级样本、吞吐和延迟
逐项与历史文件相同，当前运行时配对后联合门槛仍通过。

## 后续改进：慢链路专用 Prompt 传输分块

在 C1 三集群维持原稀疏准入边集与 M3 选路，只把带宽不超过 50 MB/s 的
计算链路上的 Prompt 激活传输切成 4 MiB 块，让已就绪 Decode 在块间
有发送机会。1 MiB 版本先在未见正式种子 201/202/203 暴露 GPU 工作
护栏失败；随后另用开发种子 151/152，按事前规则从 2 MiB 与 4 MiB
选出 4 MiB，再冻结新正式种子 301/302/303、每格 1800 秒的协议。

新正式三种子相对稀疏门控：P95 TPOT 逐种子下降 14.71%–17.05%，
共同完成 TPOT 下降 13.88%–16.58%，吞吐上升 0.58%–0.93%，
GPU 秒/token 增加 3.06%–4.99%；各自通过预设的 +5% GPU 工作
上限及其他护栏。相对完整 V3，TPOT 下降 11.60%–13.41%，
GPU 秒/token 下降 26.92%–28.04%。4 MiB 的分块暂停次数比同轨迹
1 MiB 少约 79%，TPOT 高 5.16%–7.50%。种子 303 的 GPU 增量
为 **4.9926%**，离上限极近；种子 302 的 TTFT 相对 V3 **上升
3.87%**，不能写成所有指标均优于 V3。

1 MiB 的独立正式种子 201/202/203 虽使 TPOT 相对稀疏门控下降
21.57%–23.01%，GPU 秒/token 却增加 5.85%–10.65%，**未通过**
事前 +5% 上限；该失败不被 4 MiB 的后续成功覆盖。C1 单集群、C2、
C3 的 60 秒无作用烟测均无分块暂停，门控与 4 MiB hook 的请求、路径、
延迟、吞吐和 GPU 忙碌逐项相同。

按后续请求，另在**已观察过旧 V3/门控结果的种子 0/1/2**上运行了相同组合的
1800 秒补充复验。成功窗口相对门控的 P95 TPOT 逐种子下降 13.80%–16.85%，
GPU 秒/token 增加 2.31%–4.15%；冻结数值护栏逐种子通过。**执行完整性有保留**：
种子 2 的同一冻结实现曾两次因模拟器 `int + coroutine` 异常中断；随后两次
完整结束的关键指标一致。失败文件及[执行说明](../work3_chunk_012/EXECUTION_NOTES_CN.md)
保留，不能把这组写成首次运行无故障的独立未见种子验证。

分块 Prompt 传输并安排 Decode 的思想已有
[MoLink](https://aclanthology.org/2025.findings-emnlp.957/) 等先例。
本轮证明的是当前仿真和已测拓扑中，稀疏路径准入与慢链路专用分块
组合的系统收益及权衡；尚不能宣称分块本身或该组合已证明独立新颖，
也没有真实 GPU 系统结果。

## 失败路线及如何处理

- 动态路径空间、等待凑批和短时域控制的既有负结果保留在各实验目录；
  它们不能被本次静态准入结果“覆盖”。
- 新实现的 `0.5 × λ_decode × S_prompt²` 入场链路价格在 C1 三集群的
  两条开发轨迹未通过预定的全体/共同完成 TPOT 与 TTFT 联合门槛。
  代码确实改变路由，失败结果原样保留，不调权重补过。
- C2/C3 的 300 秒迁移开发门槛也未通过：C2 种子 124 全体 TPOT
  上升 10.51%，共同完成请求 TPOT 只上升 0.12%。长窗口结果不抹去
  这个短窗口风险；论文必须同时报告它，说明固定窗口尾延迟对样本组成敏感。
- 后续 [四条高速绕行边单边消融](../work3_detour_ablation/RESULTS_CN.md)
  在 C1 三集群种子 121/122 的 300 秒开发窗口中，四个候选均未通过事前
  筛选。移除 20→22 虽使全体/共同完成 P95 TPOT 均值分别下降 2.89%/2.93%，
  但吞吐下降 0.95%，超过预设的 0.5% 护栏；因此未进入正式长窗口。
- 后续 [画像指导的边增补](../work3_profiled_expansion/RESULTS_CN.md)
  在开发种子 131/132 中三种候选均未通过联合筛选，不能据此修改
  原稀疏准入边集。

## 可写与不可写

可写：**在四个已测异构资源池/拓扑的仿真正式窗口中，限制无必要的路径
分散减少了单位输出的 GPU 忙碌工作，并在已注册的性能护栏下维持服务表现；
当存在跨集群慢链路时保留少数高速绕行边。** C1 三集群的另一个
独立注册的未见种子长窗口还显示，4 MiB 慢链路专用分块可进一步
降低尾延迟，同时以不足但接近 5% 的单位 GPU 工作增量换取该收益。

不可写：对所有拓扑的无条件 TPOT 改善、统计意义上的非劣效证明、
动态切换必要性、链路价格有效性、真实 GPU 集群收益或已证明的独立新颖性。
尤其 C1 三集群种子 2 的 TPOT 高于 V3 3.76%，原 +2% 边界只是
三种子均值规则，且是在较严格开发门槛失败后重新注册。
