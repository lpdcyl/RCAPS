# 近邻机制工程适配修正：2026-10-27（Asia/Shanghai）

51 个机制/环境验证窗口已全部完成，冻结源码和结果未修改。追加近邻机制在首次 60 秒工程检查中出现 `Inference layer is not continuous!`，没有启动正式窗口、没有生成论文性能结果。

根因：最初的逐层 DP 允许请求在 GPU 驻留层段中途转发，而共同模拟器 `ComputeNode.finish_execution` 总是执行到驻留层段末端才转发。抽象路径连续并不能保证该执行器按抽象路径中途退出。该问题属于新增机制适配与执行器接口不一致，不能解释为 Parallax 性能差或原系统失效。

修正：保留论文 P2 式最小累计延迟目标，将 GPU 切换限制到共同执行器要求的驻留层段末端。这与当前 RCAPS 的可执行转移边界一致；额外约束写入每份结果的 `comparison_identity.deviations`。对照仍明确称 Parallax-inspired 机制替换，不称完整 Parallax 或无约束 P2 复现。

旧代码、错误、工程检查、队列状态及日志保存在 `neighbor_preflight_attempt1/`；无正式性能数据被覆盖。新增回归例专门构造“早退路径代价最低但执行器不支持”的情况，使用穷举的可执行链检验 DP 结果。工程检查通过后才登记原计划的 12 个正式窗口；不修改负载、种子、延迟画像或参数以追求正结果。
