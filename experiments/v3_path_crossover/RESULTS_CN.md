# 固定拓扑下的路径策略交叉实验结果

实验类型：离散事件仿真（simulation_only），不是实体 GPU 集群部署实测。正式种子为 0、1、2，每格 1800 仿真秒、零预热、窗口末不排空；共 54 格。

同一 C1_multi 24 GPU 部署；三策略均使用相同 M3 排序和 KV 生命周期预约。跨集群计算链路在 crosslink_4x 条件下带宽乘 4，其他物理量固定。

负载是生成器的输入加输出 token 到达速率目标；吞吐只计窗口内完成的输出 token。两者口径不同，不能直接相除解释为利用率。不同种子的实际到达速率略有变化，但同一负载/种子的六个条件严格共用同一轨迹。

## 交叉判定

符合预注册规则的方向性交叉：
- network 轴：high/nominal 的 full → high/crosslink_4x 的 partial；三种子中 3/3 同向。
- load 轴：middle/nominal 的 partial → high/nominal 的 full；三种子中 3/3 同向。

三种子仅作描述性证据，不代表统计显著性。吞吐和完成率用于尾延迟胜者的护栏；不同条件间的绝对吞吐不直接互比。

## 证据范围

该矩阵只检验固定路径空间偏好是否随负载或链路容量改变。它不能替代动态自适应控制器、42 GPU 泛化，以及少 GPU 相比 Helix 全 GPU 的对比实验。主指标按仿真事件时间统计，未把调度器在 CPU 上的真实计算时间加入请求延迟。校验细节见 validation.json 与 INTEGRITY_NOTES_CN.md。
