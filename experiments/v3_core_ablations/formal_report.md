# V3 核心递进消融：C1 两拓扑

A=单边界+静态 DAG，B=最多双边界+静态 DAG，C=单边界+实时 M3，D=V3 多级布局+实时 M3。M1 为同一纯图建模。B−A 是开放多级布局的效果；D−B 是 V3 布局上的实时状态收益；交互量=(D−B)−(C−A)。

同拓扑、同种子、同负载、同 1800 秒零预热不排空窗口比较。新跑和复用来源均在 JSON 索引中记录 SHA256。

## 本轮判定

12 个新高负载静态窗口全部完成，C/D 各 6 个正式窗口经哈希和执行语义审计后复用；未触发预设的低负载回退。单集群 B−A 的平均吞吐增加 4.896 token/s，P95 TTFT 下降 0.757 秒，P95 TPOT 下降 0.298 秒，三个种子方向一致；这支持多级 M2 在该拓扑上的结构价值。三集群 B−A 的吞吐只增加 0.013 token/s，且所选结构仍为单边界，不能据此宣称多级结构在三集群也产生收益。

在 V3 布局上引入实时 M3（D−B）后，单集群平均吞吐增加 6.915 token/s，P95 TTFT/TPOT 分别下降 0.691/0.546 秒；三集群相应为增加 3.381 token/s，下降 1.137/0.520 秒。完成率和积压也同步改善。单集群吞吐交互量为 −4.292 token/s、TTFT 交互量为 +0.474 秒，未显示 M2 放大 M3 收益；三集群交互量接近零或指标方向不一致。因此不作正向协同主张。

已有完整系统对照见 `experiments/v3_release/v3_vs_helix.json`：V3 相对 Helix ILP 的平均输出吞吐增幅为单集群 9.63%、三集群 21.16%。该外部对照仅作完整系统背景，不代替本轮四格归因。

## 解释范围

已完成请求的 P95 受窗口截尾影响；逐种子完成率、末端积压、待完成请求驻留时长和共同完成请求尾延迟见 JSON 分析文件。路径数是结构与使用的描述，不单独证明性能因果。三个种子不用于统计显著性声明。
