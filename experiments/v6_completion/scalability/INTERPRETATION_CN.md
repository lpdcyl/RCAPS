# 扩展性结果口径

合成物理池分别有 48 和 96 张 GPU，A100:L4:T4=1:2:3。离线搜索从完整物理池选择部署；48 GPU 池使用 8 张、部署 DAG 为 10 条边和 2 条完整路径；96 GPU 池使用 11 张、部署 DAG 为 13 条边和 2 条完整路径。具体搜索耗时、评分次数与原始 SHA256 见各池 search_result.json。

因此在线 _route 耗时是在较大候选池搜索后得到的小型部署 DAG 上测得，不代表 48/96 张 GPU 全部活跃时的路由耗时。不能据此声称在线路由复杂度已在 96 活跃 GPU 上验证。原始指标为 Windows gllm 环境的 CPU 墙钟时间，跨机器不宜直接比较。
