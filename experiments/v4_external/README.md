# V4 外部比较补充批次

正式 seed 0/1/2、1800 秒、零预热、不排空；参数不根据结果调整。本批与 V4 主批次分开冻结，旧模拟器、V3 和外部基线文件均不修改。

27 个新窗口：两拓扑共同负载（单 350、三集群 160）的 Helix/Swarm/SP 共 18 格；单集群 350 的 V3 对照 3 格；高负载 Helix（单 700、三集群 320）资源计量 6 格。V4 和三集群低负载 V3 已在主批次，不重复。

唯一变化是启用同一被动 ResourceProfile。SP 使用原全局轨迹分配与调度，并汇总所有分区的 GPU 忙碌，GPU 名称加分区前缀避免相互覆盖。每个正式结果必须与旧结果的端到端指标、路由和逐请求样本完全一致；新增加的 GPU 计量另行保存。

沿用 `../v4_formal/ENVIRONMENT_CN.md` 中环境。先执行 `python -m experiments.v4_external.run --phase preflight`（seed 0、60 秒工程等价性，不计论文结果），通过后 `--phase freeze`，提交冻结协议/清单，再 `--phase queue`。最多两进程并行；任何运行错误停止后续派发，保留失败，不自动重试。

本批结束不意味着网络、画像和窗口敏感性全部完成；GPU 工作也不等于能耗。
