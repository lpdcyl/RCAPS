# V2 创新性核对范围

本文件只界定当前方法可能的差异点，不把检索结果当作“首次提出”的证明。

| 已有工作 | 已公开的相关能力 | 对 V2 论证的约束 |
| --- | --- | --- |
| [Helix](https://arxiv.org/abs/2406.01566) | 异构 GPU 与网络上的模型放置、请求调度联合优化 | 不能把“联合放置与调度”本身写成新贡献 |
| [HexGen](https://proceedings.mlr.press/v235/jiang24f.html) | 异构、跨数据中心环境中的非对称张量／流水线划分与调度 | 不能把异构非对称划分概括为 V2 首创 |
| [OServe](https://proceedings.mlr.press/v306/jiang26k.html) | 根据工作负载调整异构模型部署 | 不能笼统宣称 V2 首次实现自适应部署 |
| [ShuntServe](https://arxiv.org/abs/2606.18600) | 联合选择节点配置、并行策略和层分配 | 自动决定层数与设备组仍需限定具体机制再比较 |

V2 当前实现的具体研究对象是：**在固定 24-GPU 池和不更换在线调度器的条件下，在显存与真实链路约束内选择多 GPU 共享前缀、复制后缀数、设备分组和层边界，并检验它相对同一搜索器固定双后缀结构的增量。**离线六请求事件图是启发式代理，不提供全局最优或在线热点预测保证。

论文写作前仍需阅读全文，特别核对是否已有等价的共享层复制树和可拼接执行图；若已有重合，应将贡献进一步收窄到约束组合、求解策略及受控实验，并补齐对应基线。当前 V2 只是在现有 RCAPS 基础上验证一个新结构搜索方向，正式创新主张取决于完整实验和文献核对。
